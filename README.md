# 抖音自媒体广告推荐系统

## 项目简介

本项目是一个完整的自媒体广告推荐与合作管理系统,旨在解决广告主与内容创作者合作过程中的信息不对称、流程繁杂、效率低下等问题。系统支持抖音、小红书、哔哩哔哩等多个自媒体平台,为广告主、合作者(内容创作者)和平台管理员提供全方位的服务。

**部署地址**: http://112.124.2.50:5001/

系统采用前后端分离架构,后端使用Flask框架,前端使用HTML、CSS、JavaScript和Bootstrap 5,数据库使用MySQL,实现了智能推荐匹配、任务全生命周期管理、实时消息通讯、财务管理等核心功能。

---

## 系统角色

### 1. 广告主
发布广告任务、寻找合作者、管理合作项目、进行沟通与财务管理的企业或个人用户。

### 2. 合作者(内容创作者)
在各自媒体平台拥有粉丝基础,寻找广告机会、接受合作邀请、执行广告任务的内容创作者。

### 3. 管理员
平台运营管理人员,负责用户管理、内容审核、财务监督、数据分析和系统配置。

## 一、广告主端功能

### 1. 首页与数据概览

**功能说明:**
为广告主提供业务数据聚合视图,包括任务统计、合作申请统计、互动数据、推荐合作者和平台通知。

**使用方法:**
1. 登录后进入广告主首页
2. **数据概览**: 查看任务总数、进行中任务、已完成任务、收到的申请、发出的邀请、待处理请求、任务浏览量、关注数、收藏数等核心数据
3. **推荐合作者**: 浏览"为您推荐"、"热门推荐"、"新晋合作者"三类推荐,查看合作者详情或直接发送邀请
4. **平台通知**: 查看系统通知,点击查看详情或标记已读

### 2. 个人资料管理

**功能说明:**
管理企业基本信息、账户安全设置和财务账户。

**使用方法:**
1. 进入"个人中心"
2. **基本资料**: 查看企业名称、行业、LOGO、联系方式、账户余额、历史合作数量、平均预算等信息
3. **信息修改**: 上传企业LOGO、修改企业名称、行业、邮箱、电话,点击"修改密码"更改登录密码
4. **财产管理**: 查看账户余额和交易记录,点击"充值"选择金额完成充值,点击"申请提现"填写提现信息

### 3. 广告任务管理

**功能说明:**
发布广告任务并管理任务全生命周期,包括待合作、进行中、已完成和已取消状态。

**使用方法:**
1. **发布广告任务**: 填写任务标题、描述、预算、截止日期、目标受众、平台要求、内容格式、内容风格和详细要求,提交发布
2. **待合作任务**: 查看已发布任务列表,点击"查看详情"查看完整信息,点击"查看合作者"查看申请者,点击"取消任务"取消任务
3. **进行中项目**: 查看正在执行的合作项目,点击"标记完成"完成项目(需账户余额充足)
4. **已完成项目**: 查看已完成的合作历史
5. **已取消项目**: 查看已取消的任务记录

### 4. 查找合作者

**功能说明:**
通过多维度筛选搜索合适的合作者,管理收藏和浏览历史。

**使用方法:**
1. **合作者列表**: 使用平台、内容形式、内容领域、最低粉丝数、内容风格、关键词等条件筛选,按粉丝量或互动率排序
2. 点击"查看详情"查看合作者完整资料(粉丝数、互动数据、内容特征、历史合作数等)
3. 点击"邀请合作"选择任务并填写邀请说明发送邀请
4. 点击"收藏"将合作者加入收藏夹
5. **收藏合作者**: 查看已收藏的合作者,可取消收藏或发起邀请
6. **浏览记录**: 查看最近浏览过的合作者历史

### 5. 合作请求管理

**功能说明:**
集中管理与合作者之间的合作邀请和申请。

**使用方法:**
1. **已发送**: 查看已发送的合作邀请,按"待回应"、"已接受"、"已拒绝"、"已取消"分组显示
   - 点击"查看详情"查看邀请完整信息和合作者回复
   - 点击"取消邀请"取消待回应的邀请
2. **已收到**: 查看收到的合作申请,按"待处理"、"已接受"、"已拒绝"分组显示
   - 点击"查看详情"查看申请详情
   - 点击"接受申请"或"拒绝申请"处理待处理申请,填写回复消息

### 6. 消息中心

**功能说明:**
与合作者进行实时通讯,管理关注和粉丝关系。

**使用方法:**
1. **我的关注**: 查看已关注的合作者列表,点击"查看详情"或"取消关注"
2. **我的粉丝**: 查看关注自己的合作者,点击"关注"或"取消关注"
3. **消息**: 与互相关注的合作者进行私信沟通
   - 左侧联系人列表显示未读消息数量
   - 右侧聊天区域发送和接收消息
   - 打开对话自动标记已读

## 核心算法

### 1. 广告主合作者推荐算法

**算法说明:**
基于加权评分模型为广告主推荐最合适的合作者,综合考虑:
- 粉丝数量(权重0.25)
- 历史合作次数(权重0.15)
- 活跃度(权重0.20)
- 领域匹配度(权重0.25)
- 风格匹配度(权重0.15)

系统会分析广告主历史任务偏好,计算候选合作者的综合评分,推荐评分最高的前5位合作者。

### 2. 合作者广告任务推荐算法

**算法说明:**
基于加权评分模型为合作者推荐最合适的广告任务,综合考虑:
- 任务预算(权重0.30)
- 任务发布新鲜度(权重0.15)
- 领域匹配度(权重0.30)
- 内容格式匹配度(权重0.10)
- 内容风格匹配度(权重0.15)

系统会根据合作者的内容特征,计算候选任务的综合评分,推荐评分最高的前5个任务。

## 技术架构

### 系统架构
- **前后端分离架构**: 前端使用HTML、CSS、JavaScript和Bootstrap 5,后端使用Flask框架
- **数据库**: MySQL关系型数据库,共定义19个核心数据表
- **推荐算法**: 基于加权评分模型的双向智能推荐

### 数据库设计
核心数据表包括:
- 广告任务表、管理员表、广告主表、合作者表
- 已归档项目表、广告主交易流水表、合作者交易流水表
- 广告主合作邀请表、合作者合作申请表
- 广告主收藏夹表、合作者收藏夹表
- 广告主关注表、合作者关注表
- 广告主发送消息表、合作者发送消息表
- 广告主系统通知表、合作者系统通知表
- 广告主浏览历史表、合作者浏览历史表
